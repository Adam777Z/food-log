# Food Log
Food Log Web App

Features:
- Add/remove/duplicate (copy) day
- Add/edit meal (name, time, calories in kcal, notes)
- Total (calculated) water & salt for meals
- Reorder meals within a day
- Daily totals of kcal, water, salt
- Backup/restore/erase data
